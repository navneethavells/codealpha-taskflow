# TaskFlow - CodeAlpha Frontend Development Project

TaskFlow is a responsive task manager built with HTML, CSS, and JavaScript. It is suitable for a CodeAlpha frontend internship GitHub submission because it demonstrates layout design, DOM manipulation, localStorage, filtering, and responsive UI behavior.

## Features

- Add tasks with category, priority, and due date.
- Move tasks across To Do, In Progress, and Done columns.
- Search tasks and filter by category or priority.
- Track total, active, completed, and completion percentage.
- Store tasks in browser localStorage.
- Toggle light and dark theme.
- Responsive layout for desktop, tablet, and mobile screens.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

Open `index.html` in any modern browser.

No installation, package manager, or backend is required.

## GitHub Pages

After uploading the repository to GitHub:

1. Open the repository on GitHub.
2. Go to `Settings`.
3. Open `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save and wait for GitHub to publish the link.

Your live link will look like:

```text
https://your-username.github.io/codealpha-taskflow/
```
